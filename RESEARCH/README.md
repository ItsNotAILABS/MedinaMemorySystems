## Papers

| Paper | Summary |
|---|---|
| [Weighted Consensus in Multi-Agent AI Systems](./WEIGHTED_CONSENSUS_MULTI_AGENT.md) | Role-weighted voting for multi-agent decision resolution. Derives weight table from Solfeggio frequency ratios. Formalizes veto, confidence floors, and winner selection. |
| [Signal-Driven Coordination in Multi-Agent AI Teams](./SIGNAL_DRIVEN_AI_COORDINATION.md) | Pub/sub communication patterns for decoupled agent architectures. Defines four signal types, four priorities, channel scoping, and coordination patterns for task assignment, escalation, and inter-team routing. |
| [Role-Frequency Alignment in Multi-Agent Architectures](./ROLE_FREQUENCY_ALIGNMENT.md) | A ten-role system tuned to Solfeggio harmonics. Derives consensus weights from Hz ratios. Introduces team resonance scoring. Analyzes five canonical team presets. |
