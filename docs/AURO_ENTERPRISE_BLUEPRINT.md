# AURO Enterprise Blueprint

## Overview

AURO (Autonomous Unified Reasoning Organization) is the enterprise operating model that NOVA OVO implements. It defines how a sovereign intelligence platform integrates with existing enterprise systems.

## Three Onboarding Modes

### CONNECT Mode
Systems remain in their native environment. NOVA OVO acts as an intelligent bridge:
- API connectors read/write to source systems
- Memory receives normalized snapshots
- Governance policies apply to all write operations
- Minimal disruption to existing workflows

### INTERNALIZE Mode  
Data is fully absorbed into NOVA's sovereign memory layer:
- All data ingested into Memory Temple
- Source systems become optional
- Full NOVA governance applies
- Maximum intelligence amplification

### HYBRID Mode
Selective per-system approach:
- Choose CONNECT or INTERNALIZE per connector
- Gradual migration path
- Balance between disruption and capability
- Recommended for enterprise transitions

## Governance Integration

All company data operations pass through NOVA's governance layer:
- Gate B controls memory write access
- Gate A controls enactment of data policies
- Audit log captures all data operations
- Proposals can modify data governance policies

## Memory Integration

Ingested company data becomes sovereign memory:
- Automatically assigned spatial coordinates
- Salience scored by relevance and recency
- Doctrine alignment checked against N1–N4 rings
- Available to all model families for reasoning
