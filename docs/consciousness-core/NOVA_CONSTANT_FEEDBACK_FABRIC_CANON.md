# NOVA Constant Feedback Fabric Canon

## Overview

The Constant Feedback Fabric is the network of signals that flows continuously through NOVA OVO, connecting every subsystem into a coherent intelligence loop.

## Feedback Channels

### Memory → Organism
Every memory access updates the organism's cognitive register. High-salience retrieval increases COG. Failed retrieval decreases SOM.

### Governance → Gates
Proposal enactment directly modifies gate states. Gate changes propagate immediately to all subsystems.

### Model → Memory
Each model invocation produces artifacts that are candidates for memory storage. The Memory Curator model scores and routes these artifacts.

### Organism → Model Routing
The organism's dominant register influences model routing:
- SOV dominant → prefer Governance or Strategist
- COG dominant → prefer Analyst or Builder
- AFF dominant → prefer Memory Curator
- SOM dominant → prefer Operations or Risk

### Company → Memory
Company connector syncs continuously feed the memory layer with new N11 ring entries. These are automatically scored for doctrine alignment.

### Replay → Organism
Replay of past sessions can restore organism state to a prior beat, enabling "what-if" reasoning with historical context.

## RECITAL_PLUS_ONE in the Fabric

The fabric amplifies resonance across every feedback loop. A message that passes through Memory → Organism → Model → Memory has its resonance amplified by (1 + 0.15)³ = 1.52×.
