# NOVA Sovereign N1–N12 Macro Hierarchy Canon

## The Twelve Rings

The N1–N12 hierarchy defines the authority and abstraction structure of all information within NOVA OVO.

### N1 — Sovereign Core
The innermost ring. Contains founding doctrine, constitutional principles, and organism identity. Only the Sovereign principal can write to N1. Gate A and C must both be green.

### N2 — Doctrine Layer
Constitutional principles and standing law (including RECITAL_PLUS_ONE). Gate A required for modification.

### N3 — Governance Layer
Active governance structures, gate protocols, and voting frameworks.

### N4 — Strategic Layer
Long-range vision, strategic frameworks, and macro-level plans.

### N5 — Operational Layer
Active operations, workflows, and execution plans.

### N6 — Tactical Layer
Short-term tasks, tactical responses, and immediate actions.

### N7 — Memory Layer
General episodic and semantic memories from active sessions.

### N8 — Analytical Layer
Analysis outputs, patterns, and derived insights.

### N9 — Communication Layer
Inter-system messages, notifications, and relational records.

### N10 — Interface Layer
UI state, user preferences, and presentation data.

### N11 — External Layer
Company connectors, external API responses, and third-party data.

### N12 — Archive Layer
Historical records, deprecated versions, and cold storage.
