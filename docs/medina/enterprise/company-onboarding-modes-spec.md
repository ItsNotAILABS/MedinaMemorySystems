# MEDINA V1 Company Onboarding Modes Specification

Classification: BUILDER_CONFIDENTIAL

## Onboarding Modes

### 1) Connect
Integrate existing company systems with MEDINA.

- Preserve current source-of-truth systems
- Establish connector-level policy controls
- Record replay trails for every workflow

### 2) Internalize
Replicate selected company operations into MEDINA-native substrate.

- Migrate operational domains with lineage
- Preserve policy and permission semantics
- Build MEDINA-native replay continuity

### 3) Hybrid
Run Connect and Internalize in tandem with reconciliation.

- Dual-run operation enabled
- Divergence detection per cycle
- Reconciliation ledger required

## Enterprise Guarantees

- Tenant isolation mandatory
- Role-based access mandatory
- No silent privilege changes
- Day-1 support for real workflow execution
