# MEDINA V1 Runtime Organism Contract

Classification: BUILDER_CONFIDENTIAL

## Core Principle
The runtime is a beat-driven organism where macro state must absorb all micro domains every cycle.

## Beat Contract

At each beat:
1. Ingest macro field state
2. Ingest micro domain deltas
3. Validate no orphan micro signal condition
4. Execute dual-read
5. Produce lawful proposals
6. Run gate checks
7. Commit accepted transitions
8. Emit replay + evidence

## Integrated Runtime Components

- heartbeat
- cardio-cerebral
- cardio-neural
- memory temple
- feedback fabric
- law engine
- risk/defense
- value/economy

## Rejection Conditions

Reject beat finalization if any of the following occur:
- orphan micro signals remain
- dual-read fails
- law epoch duplication detected
- gate check fails for required operation class
