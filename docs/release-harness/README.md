# Medina Memory Systems Ecosystem Release Harness

This harness turns `ItsNotAILABS/MedinaMemorySystems` into the memory/continuity feeder for the NOVA model-family root.

## Purpose

The repo feeds persistence, recall, continuity, provenance, and memory-boundary evidence into NOVA.

## Release package

- `docs/release-harness/release-packages/v1.0.0/RELEASE.md`
- `docs/release-harness/release-packages/v1.0.0/release-manifest.json`

## Model

- Medina Memory Continuity Model: persistent recall contracts, memory scope boundaries, evidence manifests, and operator-controlled data retention.

## Promotion gates

1. CI success.
2. Operator approval.
3. Privacy review before external data ingestion.
4. Evidence receipts for persistence/recall claims.

## Boundaries

- no unbounded memory retention claim
- no perfect recall claim
- no private data exfiltration
- no hidden ingestion
- operator approval required
