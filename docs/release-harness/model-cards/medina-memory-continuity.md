# Model Card: Medina Memory Continuity

## Release

`medina-memory-continuity-v1.0.0`

## Role

Provides continuity, recall, provenance, memory-boundary, and persistence evidence for the NOVA ecosystem.

## Inputs

- memory records
- provenance metadata
- operator approvals
- retention policies
- evaluation receipts

## Outputs

- memory release manifests
- continuity evidence
- recall boundary reports
- promotion evidence for NOVA main

## Task capability

- Package memory-system evidence.
- Document persistence and recall contracts.
- Validate privacy and operator gates.
- Feed memory readiness into NOVA.

## Non-capabilities

- Does not guarantee perfect recall.
- Does not authorize hidden ingestion.
- Does not bypass privacy boundaries.
- Does not claim unlimited retention.

## Evaluation

The release harness validates artifact presence, schema alignment, banned memory/privacy claims, and explicit operator approval gates.
