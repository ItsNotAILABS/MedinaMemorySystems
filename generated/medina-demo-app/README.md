# Medina Demo App

Built with **Medina Company App Builder**.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

```bash
medina-deploy vercel --project medina-demo-app
```

## Stack

- Frontend: Next.js 15 + React + Tailwind
- Backend template: python
- Deploy target: saas-vercel

1. npm run build
2. vercel --prod
