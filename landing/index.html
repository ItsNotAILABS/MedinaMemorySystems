MIT Packages

Two packages. Both drop-in.

Extracted from the multi-agent team engine. Use one or both. No dependencies on anything proprietary. No lock-in.

consensus-engine
Weighted role-based voting for multi-agent systems. Veto, confidence floors, dissent tracking. Typed authority domains per decision type.
NEW
agent-signal
Pub/sub signal bus for AI agents. BROADCAST, DIRECT, ROLE, and URGENT signal types. Decoupled coordination for any agent team.
MIT
quick-start.ts
// Install the two MIT packages
npm install consensus-engine agent-signal

// Build a consensus-driven agent team
import { ConsensusEngine } from 'consensus-engine';
import { SignalBus } from 'agent-signal';

const consensus = new ConsensusEngine({ roles, confidenceFloor: 0.72 });
const bus = new SignalBus();

// Each agent submits output as your AI calls return
bus.emit({ type: 'BROADCAST', payload: result, from: 'analyst' });
const decision = consensus.resolve('task-001', outputs);

// ✓ decision.approved — decision.winner — decision.dissent
