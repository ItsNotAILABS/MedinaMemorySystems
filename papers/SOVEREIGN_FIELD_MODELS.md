## Architecture Integration

### ULRI Routing

All 120 field models are registered in the ULRI (Unified Layered Routing Intelligence) substrate at organism boot. Every prompt scored by the system routes through their resonance functions. A query about streams, audio, or GPU computation will surface the relevant field sovereign as a routing candidate.

### Resonance Formula

For each field model:

```
resonance(input) = min(0.95, keywordHits / totalKeywords × 3)
```

Domain keywords are seeded per domain (e.g., `stream`, `flow`, `pipe` for STREAMS_SOVEREIGN). Model-level tokens from the sovereign name, Latin name, and description are added. The combined keyword set participates in cross-domain resonance scoring.

### Doctrine Injection

Field models are registered with `kind` values (`substrate`, `pattern`, `compiler`, `intelligence`) that determine how the ULRI organism affinity system weights them against the four organism registers (cognitive, affective, somatic, sovereign).

| Domain | ULRI Kind |
|---|---|
| STREAMS, WEBRTC, COMPONENTS, WORKERS, CANVAS, SVG | `substrate` |
| OBSERVERS | `pattern` |
| XR, AUDIO | `intelligence` |
| WASM, GPU, GL | `compiler` |

### Expansion Fields

Each field model's `expand()` function returns the complete list of all 10 sibling models in its domain — enabling ULRI's field-of-possibilities computation to surface related sovereign units when any one model is activated.
