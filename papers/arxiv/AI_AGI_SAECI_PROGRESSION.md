## 2. Stage 1: Artificial Intelligence (AI)

### 2.1 Narrow AI Characteristics

| Characteristic | Description |
|----------------|-------------|
| **Task-specific** | Designed for one task or narrow domain |
| **Training-bound** | Limited to training distribution |
| **Tool-like** | Used by humans, not autonomous |
| **Interpretable** | Behavior follows design |
| **Controllable** | Easy to start/stop/modify |

### 2.2 Current AI Capabilities

```
CURRENT AI CAPABILITIES:

PERCEPTION:
• Computer vision (object detection, segmentation)
• Speech recognition (transcription, speaker ID)
• Natural language understanding (parsing, intent)

GENERATION:
• Text generation (GPT, Claude, etc.)
• Image generation (Diffusion, GANs)
• Code generation (Copilot, etc.)
• Speech synthesis (TTS)

REASONING:
• Logical inference (limited)
• Mathematical reasoning (with errors)
• Planning (constrained domains)

LEARNING:
• Supervised learning (labeled data)
• Reinforcement learning (reward-shaped)
• Transfer learning (related domains)
```

### 2.3 AI Limitations

| Limitation | Description |
|------------|-------------|
| **Brittleness** | Fails on out-of-distribution inputs |
| **Hallucination** | Generates plausible but false content |
| **No true understanding** | Statistical patterns, not meaning |
| **No common sense** | Misses "obvious" implications |
| **No self-awareness** | Cannot reflect on own cognition |

7. ACT autonomously toward goals
