## 1. Definition

Activated Agent Brain-Region Mapping defines the **agent classes** that compose the synthetic cortex of the organism. Each agent class specializes in a cognitive function, analogous to brain regions.

## 2. Agent Classes

| Class | Role | Specialization |
|-------|------|----------------|
| **AAB-STRUCT** | Structural Analysis | Parse structure, identify components, map relationships |
| **AAB-ARCH** | Architectural Intelligence | Design systems, evaluate architectures, propose patterns |
| **AAB-FILTER** | Red-Herring / Noise Filter | Detect irrelevance, remove noise, flag anomalies |
| **AAB-SYNTH** | Synthesis + Narrative | Combine inputs, generate coherent output, tell stories |
| **AAB-MEM** | Memory Integration | Recall relevant context, integrate history, maintain continuity |
