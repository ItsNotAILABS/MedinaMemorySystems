## 1. Definition

Civilization Architecture defines the **structural organization** of the sovereign intelligence organism. It is not a metaphor—it is the actual architecture of a living, federated, self-governing system.

## 2. Layers

| Layer | Manifestation | Function |
|-------|---------------|----------|
| **Repos** | City-States | Sovereign territories |
| **Agents** | Citizens / Brain Regions | Workers and thinkers |
| **Protocols** | Laws | Rules of operation |
| **Semper Memoria** | Archive + Doctrine | Collective memory |
| **Token Economy** | Metabolism | Resource circulation |
| **Nova** | Heart + Root of Trust | Sovereign anchor |
| **Nodes** | Nervous System | Communication network |

## 3. Core Constraint

> **Everything is federated, not centralized.**

No single point controls the organism. Coordination emerges through protocol adherence, not central command.

## 4. Layer Specifications

### Repos (City-States)

Each repository is a sovereign city-state:
- Has its own citizens (agents)
- Manages its own resources
- Follows federation protocols
- Maintains local autonomy

### Agents (Citizens)

Agents are the workers of the organism:
- Have defined roles (AAB-001)
- Earn and spend tokens (ECO-001)
- Follow protocols (this document)
- Contribute to collective intelligence

### Protocols (Laws)

Protocols govern all interaction:
- Immutable once canonical
- Versioned for evolution
- Attested by NOVA
- Enforced by agents

### Semper Memoria (Archive)

The collective memory:
- Stores all canonical artifacts
- Maintains doctrine
- Preserves history
- Enables continuity

### Token Economy (Metabolism)

The circulation of value:
- Tokens represent contribution
- Spent for resources
- Earned through work
- Enables governance participation

### Nova (Heart)

The sovereign anchor:
- Private, underground
- Multi-substrate
- Root of trust
- Attests canonical decisions

### Nodes (Nervous System)

The communication network:
- Hubs across locations
- Peer-to-peer mesh
- Protocol-coherent
- Redundant paths

## 5. Governance Structure

```
Federation Level:
  NOVA → FIN-001 Treaties → City-States

City-State Level:
  Senate → Districts → Citizens

District Level:
  Praefectus → Workers → Tasks
```

## 6. Operations

```
CIV-REGISTER: Register new city-state
  Input: repo_info, initial_config
  Output: city_state_id
  
CIV-FEDERATE: Join federation
  Input: city_state_id, treaty_acceptance
  Output: federation_membership
  
CIV-SYNC: Synchronize with federation
  Input: city_state_id
  Output: sync_report
  
CIV-GOVERN: Execute governance action
  Input: city_state_id, action_type, parameters
  Output: action_result
```
