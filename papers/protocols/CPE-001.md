# CPE-001: Conceptual Persistence Engines

## Chapter 18 of the Sovereign Protocol Canon

**Protocol ID:** CPE-001  
**Version:** 1.0  
**Status:** CANONICAL  
**Role:** Keep Ideas Alive Without Disk Writes

---

## 1. Definition

Conceptual Persistence Engines define how **ideas persist** across sessions without traditional disk writes. Ideas survive through artifact chains, traces, and active reference.

## 2. Persistence Mechanism

Ideas persist through:

| Mechanism | How It Works |
|-----------|--------------|
| **CBI artifacts** | Structured cognitive objects |
| **Semper Memoria** | Long-term canonical storage |
| **MAE traces** | Reasoning execution records |
| **Active reference** | Being used keeps alive |

## 3. Persistence Rule

> **Anything referenced across ≥N cycles → candidate for canonization in Nova.**

The threshold N is configurable (default: 3 cycles).

## 4. Lifecycle

```
Idea Lifecycle:
1. Created (CBI-CREATE)
2. Used in reasoning (MAE-EXEC)
3. Referenced again (N-1)
4. Reference threshold reached (N)
5. Promotion candidate identified
6. Quality review (AAB-FILTER)
7. Canonization (CBI-PROMOTE → NOVA-ATTEST)
8. Permanent persistence (Semper Memoria)
```

## 5. Operations

```
CPE-TRACK: Track idea references
  Input: artifact_id
  Output: reference_count, reference_history
  
CPE-CANDIDATE: Identify canonization candidates
  Input: threshold_n, quality_min
  Output: candidate_list
  
CPE-PERSIST: Ensure idea persists
  Input: artifact_id, persistence_level
  Output: persistence_status
  
CPE-EXPIRE: Mark for expiration
  Input: artifact_id, reason
  Output: expiration_scheduled
```

## 6. Persistence Levels

| Level | Description | Storage |
|-------|-------------|---------|
| Ephemeral | Single session | Memory only |
| Short-term | Multiple sessions | Hub storage |
| Long-term | Federation-wide | DCM mesh |
| Canonical | Permanent | Semper Memoria |

## 7. Reference Types

| Type | Weight | Description |
|------|--------|-------------|
| Direct use | 1.0 | Artifact used in reasoning |
| Citation | 0.5 | Referenced by another artifact |
| Derivative | 0.3 | Inspired new artifact |
| Search hit | 0.1 | Found in search |

## 8. Expiration

Ideas expire when:
- No references for expiration_period
- Quality falls below threshold
- Superseded by newer artifact
- Explicitly expired

## 9. Integration

- **CBI-001**: Artifact structure
- **MAE-001**: Reasoning traces
- **NOVA-001**: Canonization authority
- **Semper Memoria**: Permanent storage
