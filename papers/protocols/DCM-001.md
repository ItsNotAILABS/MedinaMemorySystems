## 1. Definition

Distributed Cognitive Meshes form the **global thinking fabric** of the organism. All hubs, agents, repos, and Nova exchange cognitive artifacts through this mesh.

## 2. Key Rule

> **No single point of cognitive control; only protocol coherence.**

The mesh has no central coordinator. Coherence emerges from shared protocols.

## 3. Mesh Components

| Component | Role in Mesh |
|-----------|--------------|
| **Nova** | Root anchor, canonical source |
| **Hubs** | Regional nodes, local processing |
| **Agents** | Active workers, artifact producers |
| **Repos** | City-states, sovereign territories |
| **Artifacts** | Cognitive currency, shared knowledge |

## 4. Artifact Exchange

Cognitive artifacts flow through the mesh:

```
Artifact Flow:
1. Agent produces artifact (CBI-001)
2. Artifact tagged with origin, type, quality
3. Artifact propagates to local hub
4. Hub propagates to peers (if relevant)
5. High-quality artifacts sync to NOVA
6. NOVA propagates canonical artifacts to all
```

## 5. Propagation Rules

| Artifact Quality | Propagation Scope |
|------------------|-------------------|
| Draft | Local only |
| Active | Hub + immediate peers |
| Promoted | All federation hubs |
| Canonical | Global (via NOVA-SYNC) |

## 6. Operations

```
DCM-PUBLISH: Publish artifact to mesh
  Input: artifact, scope
  Output: publication_id
  
DCM-SUBSCRIBE: Subscribe to artifact stream
  Input: criteria (type, quality, origin)
  Output: subscription_id, stream
  
DCM-QUERY: Query mesh for artifacts
  Input: query_criteria
  Output: artifact_list
  
DCM-ROUTE: Route request to appropriate node
  Input: request, routing_hints
  Output: routed_response
```
