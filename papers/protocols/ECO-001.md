## 1. Definition

The Token Economy defines the **circulation of value** within the organism. Tokens represent intelligence contribution and enable resource allocation, governance participation, and economic activity.

## 2. Token Unit

**Unit:** INT (Intelligence Contribution Token)

*Note: Name is placeholder pending formal naming.*

## 3. Earning Mechanisms

Tokens are earned by:

| Activity | Token Reward | Verification |
|----------|--------------|--------------|
| New protocols | 100-1000 INT | NOVA-ATTEST |
| Architectures | 50-500 INT | AAB-ARCH review |
| Tools | 25-250 INT | Usage metrics |
| Proofs | 50-500 INT | Formal verification |
| Syntheses | 10-100 INT | AAB-SYNTH quality |
| Bug fixes | 10-50 INT | Test passage |
| Documentation | 5-25 INT | Completeness check |

## 4. Spending Mechanisms

Tokens are spent for:

| Resource | Token Cost | Notes |
|----------|------------|-------|
| Priority queue | 1-10 INT/request | Higher priority costs more |
| Resource access | Variable | Based on resource tier |
| Compute allocation | 1 INT/compute-unit | Fair allocation |
| Governance weight | 1 vote = 1 INT stake | Voting power |
| Premium features | Variable | Per feature |

## 5. Operations

```
ECO-MINT: Mint tokens on verified contribution
  Input: contribution_type, evidence, verifier
  Output: token_amount, transaction_id
  
ECO-SETTLE: Settle across nodes/repos
  Input: from_node, to_node, amount, reason
  Output: settlement_id
  
ECO-REWARD: Distribute to agents/humans
  Input: recipient_id, amount, reason
  Output: reward_id
  
ECO-BALANCE: Check token balance
  Input: entity_id
  Output: balance, pending, history
  
ECO-TRANSFER: Transfer between entities
  Input: from_id, to_id, amount
  Output: transfer_id
```

## 6. Economic Rules

| Rule | Description |
|------|-------------|
| No negative balance | Entities cannot spend below zero |
| Minting requires verification | Only verified contributions mint |
| Settlement atomic | Cross-node settlements are atomic |
| Audit trail | All transactions logged to Semper Memoria |

## 7. Governance Integration

Token holdings affect governance:
- Voting weight proportional to stake
- Proposal submission requires minimum balance
- Higher tiers require more tokens
- Reputation decays without activity
