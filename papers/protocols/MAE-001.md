## 1. Definition

Multi-Agent Reasoning Ecosystems define how **tasks are processed** through coordinated agent sets. Each task is routed to an appropriate agent graph, producing artifacts and earning rewards.

## 2. Pattern

```
Task Processing:
1. Task arrives
2. Task analyzed for requirements
3. Agent graph selected (AAB-ROUTE)
4. Agents fire in sequence
5. Output combined into CBI artifact
6. Contributor agents receive ECO reward
7. Trace logged to Semper Memoria
```

## 3. Agent Composition

Tasks are processed by agent sets:

| Task Type | Typical Agent Set |
|-----------|-------------------|
| Simple Query | AAB-MEM → AAB-SYNTH |
| Analysis | AAB-MEM → AAB-STRUCT → AAB-ARCH → AAB-SYNTH |
| Design | AAB-ARCH → AAB-STRUCT → AAB-FILTER → AAB-SYNTH |
| Security | AAB-FILTER → AAB-STRUCT → AAB-ARCH → AAB-SYNTH |
| Integration | AAB-MEM → AAB-STRUCT → AAB-ARCH → AAB-FILTER → AAB-SYNTH |

## 4. Operations

```
MAE-PLAN: Choose agent graph
  Input: task_description, context, constraints
  Output: agent_graph
  
MAE-EXEC: Run reasoning
  Input: agent_graph, task_input
  Output: final_output, agent_outputs
  
MAE-LOG: Emit trace to Semper Memoria
  Input: execution_id, trace_data
  Output: log_reference
  
MAE-REWARD: Distribute rewards
  Input: execution_id, quality_score
  Output: reward_distribution
```

## 5. Execution Trace

Each execution produces a trace:

```yaml
trace:
  execution_id: <unique id>
  task: <original task>
  agent_graph: <agent sequence>
  steps:
    - agent: AAB-MEM
      input: <input>
      output: <output>
      duration: <ms>
    - agent: AAB-STRUCT
      input: <input>
      output: <output>
      duration: <ms>
    # ... more steps
  final_output: <combined output>
  quality_score: <0-100>
  total_duration: <ms>
  tokens_consumed: <INT>
  tokens_rewarded: <INT>
```

## 6. Quality Scoring

| Factor | Weight | Measurement |
|--------|--------|-------------|
| Correctness | 40% | Verification against criteria |
| Completeness | 25% | Coverage of requirements |
| Efficiency | 20% | Time and resource usage |
| Clarity | 15% | Output readability |

## 7. Reward Distribution

Rewards distributed based on contribution:

| Agent Role | Reward Share |
|------------|--------------|
| Primary producer | 40% |
| Quality enhancer | 25% |
| Memory provider | 15% |
| Filter/validator | 10% |
| Synthesizer | 10% |

## 8. Integration

- **AAB-001**: Agents that compose ecosystems
- **CBI-001**: Output artifacts
- **ECO-001**: Reward distribution
- **REV-001**: Underlying reasoning
