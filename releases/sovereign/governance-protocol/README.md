## Overview

The Governance Protocol provides a constitutional framework for sovereign intelligence organisms. Every proposal flows through three gates that cannot be bypassed. Every state change requires dual consensus between Oro (executor) and Nova (doctrine guardian). Every decision has evidence, lineage, and audit trail.

**This is not a governance tool. This is the organism's constitution.**

- Proposal lifecycle management (draft → open → approved → enacted → archived)
- Three-gate enforcement system (A: Governance, B: Memory, C: Sovereign)
